[**Rotary Positonal Embedding**](https://github.com/HSaurabh0919/CTransformers/blob/main/Embeddings/rope.ipynb) : RoPE takes a fundamentally different approach by embedding positional information directly into the attention mechanism. Instead of adding position vectors to embeddings, it rotates the query and key vectors by an angle that depends on the token’s position. This rotation ensures that the dot product between queries and keys naturally encodes relative position information.
